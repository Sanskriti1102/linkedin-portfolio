# Sanskriti Kadam — LinkedIn Branding Portfolio

A responsive, interactive one-page portfolio built with HTML, CSS and vanilla JavaScript. Designed for free hosting with GitHub Pages.

## Included
- Responsive desktop and mobile layout
- Dark/light theme toggle
- Before-and-after LinkedIn screenshot comparison slider
- Scroll progress indicator and reveal animations
- Service package buttons that copy a ready-to-send inquiry
- Direct LinkedIn contact links
- Your supplied earlier and current LinkedIn screenshots

## Preview locally
Open `index.html` in a browser. For the best local preview, use VS Code Live Server.

## Publish with GitHub Pages
1. Create a new **public** GitHub repository, for example `linkedin-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and the entire `assets` folder to the repository root.
3. Commit the files to the `main` branch.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then click **Save**.
7. Wait for the deployment and open the URL GitHub Pages displays.

Your website URL will usually look like:
`https://YOUR-GITHUB-USERNAME.github.io/linkedin-portfolio/`

## Before publishing
- Review the two screenshots and crop or blur any personal information you do not want public.
- Confirm the follower figures are still the figures you want to advertise.
- Add a professional email address if you want one displayed. This version uses LinkedIn as the contact route.
- The `₹750/day` and `₹1,125/day` amounts are shown as weekly-price equivalents, not daily billing.

## Edit your content
- Text and section structure: `index.html`
- Colors, spacing and responsive design: `style.css`
- Interactive behavior: `script.js`
- Screenshots: `assets/linkedin-before.png` and `assets/linkedin-after.png`

No framework, build step, database or paid hosting is required.
